🎨 Color Picker

A modern and intuitive Color Picker web application built with React, TypeScript, and Vite.

Select, preview, and work with colors through a clean and responsive interface designed for a simple and enjoyable user experience.

✨ Features
🎨 Interactive color selection
👁️ Live color preview
🖥️ Clean and responsive user interface
⚡ Fast development experience powered by Vite
🧩 Built with reusable React components
🔷 Fully written in TypeScript
🛠️ ESLint integration for code quality
📦 Production-ready build configuration
🖼️ Preview

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Node.js
npm
Installation

Clone the repository:

git clone https://github.com/Zakaria-Ham/Color-Picker.git


Navigate into the project directory:

cd Color-Picker


Install the dependencies:

npm install

Run Locally

Start the development server:

npm run dev


Vite will start the development server and provide a local URL in your terminal.

📜 Available Scripts
Development
npm run dev


Starts the Vite development server.

Production Build
npm run build


Compiles the TypeScript project and creates an optimized production build.

Preview Production Build
npm run preview


Serves the production build locally for testing.

Lint
npm run lint


Runs ESLint across the project to help identify code-quality and style issues.
